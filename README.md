# Copy Markdown link w/ clean URL

It writes `[title](URL)` to clipboard by pressing the add-on icon.

Features:

- It extracts canonical URLs if available.
- Search queries are removed. Hash identifiers are retained.
- It works on desktop and Android.

Source code is hosted on GitHub: [ile-24556/copy-markdown-link]

You can get this extension from [Firefox Browser Add-ons][addons].

[ile-24556/copy-markdown-link]: https://github.com/ile-24556/copy-markdown-link
[addons]: https://addons.mozilla.org/ja/firefox/addon/copy-markdown-link-w-clean-url/
